Welcome to Desktop OS

An Ubuntu-based desktop for browsing, documents, files, and everyday work. “Desktop OS” is a working name.

Development system

This customization is not a certified or production-ready operating system. Back up important data before installation. Do not install on your main computer until the image has been tested.

Your everyday tools

  • Firefox: browse the web.
  • Files: organize documents and storage.
  • LibreOffice: documents, spreadsheets, and presentations.
  • VLC: play audio and video.
  • Settings: Wi-Fi, sound, displays, users, and accessibility.
  • App Center: discover compatible applications.

Keep the system updated

Use Ubuntu’s Software Updater and App Center. This project does not replace Ubuntu’s repositories or add a separate update service. Newly installed applications and snap updates may require internet access.

Compatibility and privacy

Windows and macOS applications do not automatically run here. Hardware support depends on available Linux drivers and must be tested. This project adds no telemetry service or cloud account; included applications retain their own privacy settings.

Ubuntu foundation

The installer, kernel, drivers, and package identity remain Ubuntu. This project is an independent customization, not an official Canonical product.
